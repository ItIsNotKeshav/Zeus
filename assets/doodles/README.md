# Doodle tiles

`nature.svg`, `space.svg`, `food.svg`, `travel.svg` and `play.svg` (and the
classic `../wallpaper.svg`) are 374 x 666 tiles drawn from [Lucide](https://lucide.dev)
icons, licensed ISC, Copyright (c) Lucide Icons and Contributors. The licence text
is in `../icons/LICENSE.txt`.

Regenerate them with `python3 scripts/generate-doodles.py`, which fetches the
icons named in its `THEMES` table and reuses the classic tile's placements.

`halloween.svg` is different: its icons (pumpkin, bat, ghost, web, candy, moon,
skull, cauldron, hat, candle, spider, eye, tombstone, lollipop, sparkle, cat,
potion, candy corn) are original line drawings made for Zeus in Lucide's style,
generated by `python3 scripts/generate-halloween-doodles.py`, which needs no
network. The same script writes `../icons/pumpkin.svg` and `../icons/ghost.svg`.
`../halloween-scene.svg` is the Halloween wallpaper's skyline mask.
