Zeus 0.20.1 is the first release with downloads for Linux and Mac, next to the Windows installer. The app itself is the same as 0.20.0.

## New

- **Zeus for Linux.** Packages for Debian and Ubuntu (`.deb`), Fedora and openSUSE (`.rpm`), an `.AppImage` that runs on most distributions, and a plain `.tar.gz`, for both x86_64 and aarch64.
- **Zeus for Mac.** A universal `.dmg` for Apple silicon and Intel Macs. It is not signed by Apple, so the first time, right-click Zeus in Applications and choose Open.

The Linux and Mac builds are brand new and have not had much testing yet. If something does not work, please tell me what system you are on.
