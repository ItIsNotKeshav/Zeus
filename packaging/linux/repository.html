Zeus packages

Version @VERSION@, for x86_64 and arm64. Add the repository once, and your package manager brings each new release with your other updates.

Ubuntu 24.04, Debian 13 and newer

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URL@/zeus.asc | sudo tee /etc/apt/keyrings/zeus.asc > /dev/null
curl -fsSL @URL@/zeus.sources | sudo tee /etc/apt/sources.list.d/zeus.sources > /dev/null
sudo apt update
sudo apt install zeus

Fedora 41 and newer

sudo curl -fsSLo /etc/yum.repos.d/zeus.repo @URL@/zeus.repo
sudo dnf install zeus

openSUSE

sudo zypper addrepo @URL@/zeus.repo
sudo zypper install zeus

The first install asks you to trust the key that signs every package, the one at zeus.asc.

Releases, the Windows installer, the macOS app and the AppImage are on GitHub. See the code signing policy.
